# Architecture visual

The README architecture image was generated with the built-in image generation tool and visually checked. It is an explanatory diagram, not a deployment status probe. Dashed cloud rollout boxes distinguish the permanent static website from the backend and artifact migration work in progress.

## Final design brief

```text
Use case: infographic-diagram.
Asset type: high-resolution landscape architecture image for the ENGRAM ENGINE GitHub README.
Create a polished minimalist engineering architecture diagram, wide 16:10 landscape, exceptionally readable sharp text, warm off-white canvas, deep ink typography, teal lines and very subtle coral highlights. Flat vector-like precision, rounded rectangle cards, generous whitespace, no gradients, no 3D, no decorative circuitry. Title top left: "ENGRAM ENGINE". Subtitle: "A team of agents. One evolving memory."
Show five clean horizontal bands with simple straight connectors and short exact labels:
1 top centered card "Browser workspace" with small subtitle "Start building • Personal AI keys".
2 centered card "Cloudflare Worker" with subtitle "Permanent website • API proxy". At right small dashed outlined status card "Backend migration in progress".
3 large central group titled "FastAPI + DeepAgents" with five horizontally spaced small agent cards "Coordinator", "Researcher", "Builder", "Verifier", "Curator", connected with a thin teal shared line labelled "Parallel tasks • Durable handoffs". Directly below group a slim bar "Memory Manager | Scoped context • Versioned receipts • Corrections".
4 three equal database cards, each directly connected from Memory Manager: "FalkorDB" subtitle "Memories • Sources • Causal dependencies"; "PostgreSQL" subtitle "History • Tasks • Checkpoints"; "Mem0 + Qdrant" subtitle "Fact extraction • Semantic retrieval".
5 bottom two equal cards connected from FastAPI + DeepAgents group, outside database row: "Restricted Docker sandbox" subtitle "No network • Non-root • Resource limits"; and dashed outline "Private R2 artifact store" subtitle "Cloud rollout in progress".
At far right of central group a small card "BYOK models" subtitle "Groq • OpenAI • Anthropic • More", connected only to agent group.
At bottom elegant small caption "Correct a fact → trace affected work → revise the plan".
The image must not claim all backend infrastructure is hosted on Cloudflare. Use exact text cleanly spelled, maintain all nodes, avoid crossed or tangled edges, tiny text, illegible invented labels, icons that look like vendor logos, watermark. Large readable type, diagram should feel calm and premium.
```

## Targeted revision

```text
Keep all five agent roles equally spaced and connected to the shared line. Set the upper-left title to "ENGRAM ENGINE". Preserve all other architecture nodes, labels, connections, colors and the explicit migration and cloud rollout status boxes. Keep the title clear of the browser card.
```

The image includes the coordinator, researcher, builder, verifier and curator. Current configuration, source code and verification receipts remain authoritative for implementation and hosting details.

## Brand revision

The final asset uses the public project name **ENGRAM ENGINE**. The title was changed through a targeted built-in image edit, preserving the verified architecture, all five agent roles, and the explicit migration status labels. The README references `engram-engine-architecture.png`.
