Security boundaries

  • Docker containers enforce no network, non-root execution, read-only root and resource limits; shared host kernel is not a VM boundary.
  • Model admission is separate from code-enforced session, tenant, tool and task-lease authorization.
  • Source observation timestamps select a claim under an explicit policy; they do not prove source authority or truth.
  • Procedure hashes establish exact file versions; passing tests establish only the tested behavior.

Limits of this demonstration

  • Single local run; not a general benchmark
  • Exact long repetitive tool argument fidelity probe failed; all generated artifacts require real execution checks
  • Conservative memory retrieval dependencies invalidated 8 historical fixture runs. This is not minimal semantic impact analysis.
  • Recovered multi-attempt execution with an explicitly authorized Qwen-to-Groq-20B model change, not a first-attempt or all-Qwen pass. Stopped replans and excluded debug comparison pilots are retained.
  • The correction was supplied explicitly; claim timestamps select a winner under policy and do not establish source authority.
  • The public demo depends on its host laptop and a temporary Cloudflare tunnel. The existing film predates this live validation.
